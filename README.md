# Acoustic Empire — Website

Prezentační web [acoustic-empire.cz](https://acoustic-empire.cz) — statický, dvojjazyčný (CZ/EN), hostovaný na GitHub Pages.

## Stav

Ve fázi návrhu. Obsah a struktura se řídí specifikací v `docs/` (přidá se po schválení designu).

## Rozsah (v1)

- Hlavní stránka, O nás, Služby (akustický návrh), Produkty (absorbéry, difuzory, BoomMount, Feel Fader), Reference, Kontakt
- Poptávkový formulář (externí služba, žádný vlastní backend)
- `/` = čeština, `/en/` = angličtina

## Vývoj

Statické HTML/CSS/JS, žádný build krok. Needituje se přímo v Google Drive kopii projektu — pracuje se tady, v odděleném lokálním klonu (mimo Drive sync), stejně jako u ostatních AE repozitářů (Feel Fader app/firmware).

## Nasazení

GitHub Pages z větve `main`, doména `acoustic-empire.cz` přes CNAME (Active24 DNS → GitHub Pages).
